# Sonora — Glass Audio Player

Аудиоплеер в стиле Apple Music: стеклянные панели, живой фон, спектрограммы.
Ни одной зависимости, ни одного аудиофайла, ни одной строки сборки.

## Запуск

```bash
cd sonora
node server.mjs 5173
# открыть http://localhost:5173/
```

Нужен только Node 18+ (используется встроенный `http`). Сборка не требуется:
ES-модули отдаются как есть.

## Публикация

Это статический сайт без бэкенда, поэтому он работает на GitHub Pages как есть —
достаточно залить корень папки и включить Pages в настройках репозитория
(Deploy from a branch → `main` / `/ (root)`).

Все пути в `index.html` относительные, поэтому сайт одинаково корректно
встаёт и по адресу `user.github.io`, и по адресу `user.github.io/sonora`.

Файл `.nojekyll` в корне отключает Jekyll: иначе Pages начнёт обрабатывать
папку своими правилами.

`node build.mjs` собирает `dist/sonora.html` — один самодостаточный файл без
сервера и без сети, его можно скачать и открыть двойным щелчком. Для самого
сайта сборка не нужна.

> **Про https и радио.** Сайт на GitHub Pages отдаётся по `https`, и браузер
> блокирует `http://`-поток как смешанное содержимое. Плеер пробует `https`
> автоматически, но если радио работает только по `http` — на Pages оно не
> заиграет, и в сообщении об ошибке это сказано прямо. Указывайте `https`-ссылку.

## Что внутри

**Полка пустая — музыку добавляете вы.** В комплекте нет ни одного трека.
Кнопка со слайдерами справа сверху открывает админ-панель, где музыка
добавляется прямой ссылкой — с описанием и обложкой. Плеер различает два случая
пустоты: фильтр ничего не нашёл (предложит сбросить фильтры) и музыки нет вовсе
(предложит загрузить файл или открыть админку) — кнопка ▶ на пустой полке
объясняет, куда идти, вместо того чтобы молча ничего не делать.

В форме два вида ссылки, и разница не косметическая:

- **Аудиофайл** (mp3/flac/wav/ogg/m4a) скачивается целиком и декодируется через
  Web Audio. Ему нужен **CORS**: без него браузер не отдаст байты декодировщику.
  Длительность подставляется сама.
- **Радио** играет через `<audio>`-элемент, мимо графа. Так работает с любого
  домена, но по необходимости: поток бесконечный, и `fetch()` + `arrayBuffer()`
  ждали бы ответа вечно — тело ответа просто не заканчивается. Элемент не
  подключаем к Web Audio, потому что кросс-доменный `<audio>` без CORS на
  выходе даёт тишину. Плата честная и видна: у эфира нет ни длины, ни шкалы
  времени, ни спектра. Ползунок перемотки **убирается совсем** — серый
  отключённый слайдер только провоцирует перетаскивание, которому некуда вести, —
  и вместо него появляется метка «Прямой эфир» с пульсирующей точкой. Громкость
  и пауза работают, громкость применяется к самому элементу.

**Тип определяется сам, ручной выбор — только подсказка.** Если в форме стоит
«Аудиофайл», а ссылка ведёт на поток, плеер узнаёт об этом по заголовкам:
`content-type: audio/*` при отсутствующем `content-length` — конца нет, значит и
ждать нечего. Тело ответа отменяется, ссылка уходит элементу, а найденное
запоминается — в следующий раз транспорт сразу покажет «эфир». Тот же путь
работает и наоборот: если CORS не дал прочитать даже заголовки, плеер не
отказывает сразу, а пробует отдать ссылку элементу, потому что поток с чужого
домена так играет. Пока элемент не подтвердил старт, ничего не глушится: битая
ссылка не должна остановить трек, который играл до неё.

Обложка — квадратная картинка по ссылке; если её не задать, обложка рисуется
кодом по `id` трека.

**Аудио-граф** (`scripts/audio/engine.js`):

```
голоса → busSum → EQ (low/mid/high) → компрессор → анализатор → master → выход
         ↑        ↑
      реверб (IR-конволюция) и пинг-понг дилей
```

Каждый голос имеет свой гейн, и синтезированные ноты идут **через него** — иначе
`voice.fade()` не заглушил бы старый трек и при переключении два трека звучали бы
вместе. Ревербер и дилей для синтеза берутся из посылов отдельных нот, где их
можно форматировать огибающей. Переход «эфир ↔ файл» глушит то, что больше не
играет: поток останавливается и отпускает соединение, голос — уходит в ноль.

Поддерживаются кроссфейд, seek, suspend/resume при уходе со вкладки и
watchdog окончания трека. Если браузер блокирует автозапуск, состояние
становится `blocked` — плеер честно показывает play вместо «играет, но тишина».

**Свои файлы.** Кнопка «Загрузить» и drag&drop принимают mp3/flac/wav/ogg/m4a.
ID3v2 (2.2/2.3/2.4) читается встроенным парсером, обложка берётся из кадра APIC.

**Графика.** Обложки треков рисуются на canvas по сиду `id` (или берутся из
ссылки), фон — набор
дышащих цветовых пятен, которые реагируют на низкие частоты. Три визуализатора
(hero, мини в панели, полоска в сайдбаре) сглаживают FFT.

## Админ-панель

Кнопка со слайдерами в правом верхнем углу. При первом входе задаётся пароль,
дальше панель открывается сразу.

**Сайт** — имя страницы (бренд в сайдбаре и заголовок вкладки), подпись,
описание для `meta`, акцент, фоновая картинка по URL.

**Музыка** — главный раздел, потому что полка пустая. Всё добавляется одной
формой: **что это** (аудиофайл или радио), ссылка, название, исполнитель,
альбом, жанр, описание и ссылка на обложку. У radio жанр прячется — он всё
равно «Радио». Справа от поля обложки live-превью: сразу видно, загрузится
картинка или нет, и не приходится гадать после добавления.

У каждого трека редактируются все поля и показывается превью обложки (заданная
или нарисованная по `id`), «Скрыть» убирает трек из плеера, не удаляя его,
«Удалить» — для своих треков. «Очистить полку» возвращает исходное пустое
состояние, «Экспорт» и «Импорт» переносят всю конфигурацию в JSON и обратно.

У файла при неудачной загрузке плеер показывает тост с причиной и не остаётся в
состоянии «играет». У эфира таких ошибок нет: соединение может не пройти, и
отказ `play()` или событие `error` честно переводят плеер в «нужно нажать ещё
раз».

**Пароль** — смена пароля и выход. Хранится SHA-256 с солью (если
SubtleCrypto недоступен — слабый запасной дайджест).

> Настройки, музыка и пароль лежат в этом браузере: `localStorage` и
> `sessionStorage`. Сервера нет, поэтому пароль — это замок от случайного
> открытия панели, а не граница безопасности. У того, у кого есть файлы, есть и
> `localStorage`.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Space` | пауза / воспроизведение |
| `←` `→` | перемотка ±10 с (`Shift` — ±30 с) |
| `↑` `↓` | громкость |
| `K` / `L` | предыдущий / следующий трек |
| `Shift`+`L` | лайк |
| `J` | отмотать на 15 с назад |
| `M` | mute |
| `S` | shuffle |
| `R` | режим повтора |
| `F` | лайк текущего трека |
| `Q` | шторка очереди |
| `,` | шторка настроек |
| `T` | тема |
| `/` | фокус в поиск |
| `1`…`9` | включить трек из списка |
| `⌘K` / `Ctrl`+`K` | палитра команд |
| `?` | подсказка |
| `Esc` | закрыть шторки |

## Архитектура

```
index.html            разметка + SVG-спрайт иконок
styles/
  tokens.css          переменные: цвета, стекло, тени, темы, акценты
  base.css            сброс, скроллбары, ambient-фон
  layout.css          сетка приложения, брейкпоинты 1180/980/720/520
  components.css      кнопки, чипы, панели, очередь, тосты, шторки
  player.css          hero, транспорт, плейбар, ползунки
scripts/
  main.js             композиционный корень: boot, батченый рендер, импорт
  core/               dom, prng, raf (один rAF на всё приложение), store, player
  audio/              engine (граф), synth (генератор), files (ID3v2 + импорт)
  ui/                 artwork, background, visualizer, library, queue,
                      transport, palette, settings, shortcuts, sheet, toast
  data/tracks.js      жанры и пустой каталог (музыка добавляется в админке)
```

Принципы, на которых держится код:

- **Один rAF на всё приложение** (`core/raf.js`) — модули подписываются, а не
  плодят свои кадры. Фон ограничен 24 fps, спектрограммы 30 fps, полоска в
  сайдбаре 20 fps; при выключенной анимации фон не перерисовывается вообще.
- **Батченый рендер** (`main.js`): `store` копит изменённые ключи и один раз
  за кадр дёргает только нужные перерисовки. Позиция воспроизведения пишется
  транзиентно — она не вызывает перерисовку списка и не пишет в localStorage
  на каждом кадре. У батчера есть страховка по таймеру: окно, которому отказано
  в кадрах (свёрнуто, перекрыто, на другом виртуальном столе), иначе оставило бы
  флаг «кадр уже заказан» взведённым навсегда, и интерфейс замолчал бы при
  верных данных внутри.
- **Стекло без полной перерисовки**: фон рисуется в маленький canvas и
  растягивается — размытие делает сам GPU, поэтому `filter: blur()` по
  всему экрану не нужен.

## Хранилище

`sonora.v1` в localStorage: порядок треков, очередь, лайки, позиция,
громкость, тема, акцент, EQ, кроссфейд. Сбросить — «Настройки → Сбросить всё».

`sonora.admin.v1` — настройки сайта, правки и свои треки, пароль (соль + хеш).
`sonora.admin.session` в sessionStorage — признак входа, живёт до закрытия
вкладки. Выгружается и загружается обратно из админ-панели.

## Совместимость

Chrome/Edge 111+, Safari 16.4+, Firefox 128+. Нужны ES-модули, Web Audio,
`backdrop-filter`, `color-mix()`, `dvh`.
